# 当前问题与提交验证记录

更新时间：2026-09-26。本文记录提交时的已知问题，不代表故障已修复或源码已烧录。

## CAN1 故障仍未解决

- X 轴调参曾触发 `ROUND STOP MOTOR FEEDBACK LOST`，随后停车状态的四轮反馈恢复新鲜，说明故障可能间歇出现。
- 后一次 X 调参在输出约 `0.180 m/s` 时触发 `ROUND STOP CAN FAULT`。`ESR=0x007C0041` 对应 TEC=124、REC=0、LEC=4、EWGF=1；随后 `ESR=0x00840043` 对应 TEC=132、REC=0、LEC=4、EWGF=1、EPVF=1、BOFF=0。发送错误已进入错误被动状态，不能仅归结为软件队列阻塞。
- 故障后多个电机 `AGE_MS` 达 12–21 秒，`SEQ` 基本停止增长；运动命令被 `CAN=0 OPS=1` 安全门禁拒绝。复位开发板后，四轮反馈恢复至约 2–40 ms，用户手动以 `0.060 m/s` 前进和横移成功。
- 停车时曾出现累计 `TX_TIMEOUT=140`、`STALL_REC=8`、`CAN_DROP=270`，但两次停车读数没有继续增加；累计计数不能证明当前仍在出错。
- 当前证据支持 CAN1 发送错误及反馈中断，尚不能确定根因。优先检查终端电阻、接线、共地、收发器和运动负载下电机供电，同时检查发送调度及故障恢复。低速手动成功不能证明较高负载的调参链路稳定。
- 后两次异常中止的轮次不能作为有效 PID 验证结果。下一次应保留复位前的两组 `CAN STATUS`、`MOTOR FEEDBACK` 和完整逐轮 CSV，核对 TX_OK/RX/SEQ 的增长以及 TEC/REC、反馈年龄和恢复计数。
